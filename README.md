# Тестовое: два макета

Вёрстка двух макетов из Figma в одном проекте.

- `/svetly/` — «Светлый Дом» (лендинг Додзё Медиа): десктоп, мобилка, меню, состояния.
- `/services/` — «Услуги и форма записи» (в работе).

## Стек

Vite + чистые HTML/CSS + немного TypeScript. Без фреймворков: на лендинге JS нужен только
для мобильного меню, остальное (hover, focus-visible, адаптив) сделано на CSS.
Vite нужен для дев-сервера, сборки с хешированием ассетов и мульти-страниц.
Проект multi-page: у каждого макета свой `index.html`, поэтому якорная навигация работает нативно,
и на GitHub Pages не нужен SPA-роутер.

```bash
npm i
npm run dev      # http://localhost:5173/svetly/
npm run build    # сборка в dist/
```

Деплой: пуш в `main` → GitHub Actions собирает и публикует на Pages
(в настройках репозитория: Settings → Pages → Source: GitHub Actions).

## Как использовал AI

Макеты читал через Figma MCP: структура, токены, отступы, состояния компонентов.
Сгенерированный Figma код (абсолютное позиционирование + Tailwind) не копировал, а переписал
на семантическую вёрстку (BEM-классы, flex/grid) с CSS-переменными из токенов макета. Проверял скриншотами
в headless-браузере на 1440 / 900 / 390 px и на отсутствие горизонтального скролла.

## «Светлый Дом»: решения и допущения

- **Картинки** — заглушки в `svetly/assets/` (`hero.png`, `briskly.png`, `trade.png`, `dvor.png`).
  Замени файлы с теми же именами на экспорт из Figma (PNG 2x).
- **Токены** взяты из фрейма «Компоненты и состояния»: цвета, Oranienbaum / Manrope, размеры H1/H2 для десктопа и мобилки.
- **Состояния**: кнопка (hover — Ink, focus-visible — outline 2 px, offset 3 px), карточка (hover — #E9E3D6, focus-visible — outline),
  ссылки навигации и email (hover — подчёркивание, focus-visible — outline). Используется `:focus-visible`, чтобы обводка не появлялась при клике мышью.
- **Карточка проекта** — одна ссылка целиком, без вложенных интерактивных элементов (как требует макет).
  Страниц проектов в макете нет, поэтому ссылки пока ведут на `#projects`.
- **Мобильное меню** (< 768 px): кнопка 44×44 с `aria-expanded` / `aria-controls`; закрывается по Esc, по клику на пункт и при переходе на десктопную ширину.
  Меню сдвигает контент вниз, как во фрейме «Меню открыто».
- **Планшет (768–1023 px)** в макете не нарисован. Моё решение: hero складывается в колонку, проекты в 2 колонки, шапка остаётся десктопной.
- **Отступ над кнопкой в мобильном футере**: в макете между email и кнопкой 0 px, выглядит как случайность. Поставил 24 px, как в остальных вертикальных группах.
- **Кнопки-ссылки**: «Обсудить проект» в шапке ведёт к контактам, в футере — `mailto:`.
- **Доступность**: семантические `header / nav / main / section / footer`, один `h1`, alt у изображений, учтён `prefers-reduced-motion`.
